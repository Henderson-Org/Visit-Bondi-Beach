## Protection is enforced automatically

- `seo-protected-pages.json` is the machine-readable manifest (37 protected URLs + the approved
  redirect + the needs-confirmation rows).
- `scripts/seo-regression.mjs` loads that manifest and, for every `allowRedirect: false` URL,
  asserts: **HTTP 200**, single `<h1>`, `<title>`, meta description, **self-referencing canonical**,
  **no `noindex`**, and valid JSON-LD. Approved-redirect URLs are checked for a clean one-hop
  `301 → 200`.
- If a protected URL silently changes from **200 → 301/404**, or gains a `noindex`, the regression
  test fails and blocks the deploy — unless the migration has first been approved in the manifest.
- Run it after any deploy: `npm run seo:regression` (against a running server, or
  `BASE=https://www.visitbondibeach.com npm run seo:regression` as a production smoke test).
