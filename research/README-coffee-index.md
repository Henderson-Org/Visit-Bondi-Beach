# Bondi Coffee Index — methodology & annual-update guide

A data feature tracking the price of a standard coffee across Bondi cafés, and how it has changed
over five years. Built to be **defensible and repeatable**: raw observations → derived metrics →
presentation are separate layers, and **no price is ever invented or interpolated**.

## Files
- `research/coffee-venues.json` — the canonical venue list, extracted from the site's own
  restaurant database (`data/restaurants.json`), filtered to genuine coffee venues (cafés,
  bakeries, and brunch/breakfast restaurants) in Bondi / Bondi Beach / North Bondi / Bondi
  Junction / Bondi Road. **The database is the canonical list — we do not invent venues.**
- `data/bondi-coffee-index.csv` — the RAW observation dataset (one row per venue-year price).
- `data/bondi-coffee-index.derived.json` — computed metrics (generated by the script; never
  hand-edited).
- `research/coffee-evidence/` — one evidence file per observation (screenshot / archived
  reference / verbatim quote) so every figure is traceable and next year's refresh is easy.
- `scripts/coffee-index.mjs` — computes the index from the CSV.

## The benchmark (what counts as "a coffee")
Primary: **regular / small flat white**. If unavailable, the closest standard milk-based espresso
in this order: flat white → latte → cappuccino. The exact item used is stored per observation.
**Excluded:** large sizes, alternative-milk surcharges, extra shots, iced/filter/specialty/
flavoured drinks, takeaway-cup surcharges (unless unavoidable), and delivery-platform markups where
a direct menu price exists. Never silently substitute an incomparable product.

## Source hierarchy (per observation)
1. Venue's official menu → 2. official website → 3. official PDF menu → 4. venue-hosted ordering →
5. reputable menu platform → 6. other secondary source. For history: the **Internet Archive /
Wayback Machine** snapshot nearest the target year (prefer mid-year), archived PDFs/assets, cached
menu pages, historical social menu images, or media articles quoting a price.

## Dataset fields (`data/bondi-coffee-index.csv`)
`venue_id, venue_name, suburb, year, coffee_item, coffee_size, price_aud, source_url, archive_url,
source_date, source_type, confidence, notes`

**Confidence:** `HIGH` = official menu clearly states the price · `MEDIUM` = reputable secondary
source or close-dated archive · `LOW` = imperfect but usable. **Only HIGH/MEDIUM feed the headline
index;** LOW rows stay in the raw dataset for transparency (the compute script excludes them).

## Calculations (all in `scripts/coffee-index.mjs`)
Per year: median (the headline index), mean, min, max, p25, p75, n. Then YoY $ and % change,
five-year total $ and %, and CAGR. Plus price-band shares (<$5 / $5–5.49 / $5.50–5.99 / $6+),
cheapest & dearest, and a **matched-cohort** ("same-café") index using only venues priced in both
the earliest and latest year — which separates true coffee inflation from changes in the sample mix.

## Integrity rules (non-negotiable)
- Never invent a menu price; never interpolate a missing year and present it as observed.
- Never assume today's price held historically. Never use Google Maps "$/$$" as a price.
- Disclose delivery-app prices as such. Never claim an exact historical price without a source.
- Where evidence is sparse, **disclose coverage per year** ("historical evidence was available for
  N cafés in 2022…") rather than faking completeness. A venue need not exist in all five years.

## Updating next year
1. `git pull`; open `research/coffee-venues.json` (re-extract from the DB if venues changed).
2. Collect the new year's prices into `data/bondi-coffee-index.csv` (one row per venue), each with a
   source URL + an evidence file in `research/coffee-evidence/`.
3. `node scripts/coffee-index.mjs` → regenerates `data/bondi-coffee-index.derived.json`.
4. The page reads the derived JSON, so the new year appears automatically. Publish the YoY delta as
   the news hook and re-pitch. Keep the collection window consistent (a fixed fortnight each year).
